# 内联汇编

## 基本概念

C语言中可以内联汇编语言，提高执行效率，实现某些不方便执行的代码

## 关键字

1. \_\_asm\_\_ 关键字
ASM：内联汇编的关键字

\_\_asm\_\_是GCC中asm关键字的宏定义

可以用于简化内联汇编的代码编写

**注意**：多条汇编指令，可以用\\n来标记

2. __volatile__关键字
作用：禁止编译器优化内联汇编

## 内联汇编完整结构

```c
__asm__ __volatile__(
  "指令列表"     // 汇编指令
  : "输出操作数"  // C变量接收结果（如：=r (var)）
  : "输入操作数"  // C变量作为输入（如：r (var)）
  : "破坏列表"    // 受影响的资源（如："memory"、"cc"）
);
```
1. 输出操作数：

```c
[约束修饰符] "约束"(C变量)
```
约束修饰符：
- =：只写（默认）
- +：读写（输入+输出）
- &：早期破坏（避免输入输出共用寄存器）

约束字符：指定寄存器类型（见下表）

| 约束字符	| 含义	| 适用寄存器 |
| ------    |-----  |-------     |
|a	|绑定到eax/rax	|x86架构    |
|b	|绑定到ebx/rbx	|x86架构    |
|c	|绑定到ecx/rcx	|x86架构    |
|d	|绑定到edx/rdx	|x86架构    |
|r	|通用寄存器	    |所有架构（如eax, ebx）|
|m	|内存操作数	    |直接操作内存变量|
|g	|寄存器或内存	|灵活分配|
|ARM专用----		|
|l	|低32位寄存器（r0-r7）	|ARM Cortex-M|

注：x86中 %eax 写作 %%eax（双%转义）
